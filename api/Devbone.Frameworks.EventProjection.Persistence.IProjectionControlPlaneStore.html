Publishes reconstructible projection definitions separately from leased worker capabilities.

public interface IProjectionControlPlaneStore

Remarks

Neither collection is authoritative for events, projected state, executable code, broker progress, or replay. Definitions are republished from deployment artifacts; capabilities say only which definitions a live worker instance can currently execute.

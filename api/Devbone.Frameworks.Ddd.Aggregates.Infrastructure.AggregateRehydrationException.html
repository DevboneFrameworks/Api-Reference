Remarks

Wraps serializer and event-application failures only. Storage acquisition, unknown contracts, stream gaps, identity and lifecycle validation can throw other exceptions. The inner cause is not necessarily a data error; application policy decides whether to handle it. Do not log payload-bearing inner exceptions.

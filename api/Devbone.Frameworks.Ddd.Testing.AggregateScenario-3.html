GivenAsync(Func<TAggregate, ValueTask<IAggregateModificationResult>>, CancellationToken)

Establishes prior history by executing commands and committing them, then rehydrating a fresh aggregate so the scenario continues against stored state rather than against an in-flight instance.

public Task<AggregateScenario<TAggregate, TEntity, TIdentity>> GivenAsync(Func<TAggregate, ValueTask<IAggregateModificationResult>> arrange, CancellationToken cancellationToken = default)

Task<AggregateScenario<TAggregate, TEntity, TIdentity>>

The same scenario so calls can be chained.

Remarks

History is built by replaying real commands rather than by injecting event rows, so the events a scenario starts from are exactly the events the aggregate itself would have produced.

Exceptions

AggregateScenarioException

Thrown when an arranging command or its commit fails. A failed arrange is a broken test rather than an assertion, so it surfaces immediately instead of being mistaken for the behavior under test.

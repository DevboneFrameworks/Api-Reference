Parameters

aggregateName string

The aggregate contract name.

eventName string

The optional event contract name.

cancellationToken CancellationToken

The cancellation token.

Returns

Task<IReadOnlyCollection<IDatabaseEvent>>

The matching events grouped by aggregate identifier and, within each aggregate, in stream order.

Remarks

Reads the complete result into memory with no paging, cursor, or resume point, so it suits diagnostics and bounded rebuilds rather than a production catch-up subscription. A resumable ordered read across the whole store is tracked separately and needs a global position column the schema does not yet have.

Protects the fields a registered definition marks as protected in a serialized event payload, and unprotects the tagged values of stored payloads. Both adapters, Direct mode and the Gateway, run their payloads through this class so that protection happens once, at one place, before the envelope and the database row exist.

Remarks

The protector resolves keys through the registry it is given and never caches them itself; the caching registry of Devbone.Frameworks.Privacy is what a host registers. A registry that cannot be reached throws SubjectKeyRegistryUnavailableException out of every method, which a write side surfaces as a rejected commit. A destroyed or unknown key is not a failure: unprotection yields the placeholder the tag carries.

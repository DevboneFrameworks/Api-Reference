Remarks

Own one sampler per logical store in each process and run it from an application-owned hosted service. Replicas observing the same database report the same inventory: aggregate their gauges with max, never sum. Constructors and metric callbacks perform no I/O. A failed or stale sample emits no depth measurements. Dispose after the caller has cancelled and awaited RunAsync(CancellationToken).

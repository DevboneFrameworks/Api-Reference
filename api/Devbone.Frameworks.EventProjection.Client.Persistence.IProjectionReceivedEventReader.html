Reads which events of one aggregate stream the projection pipeline has received, and whether each was applied, from outside a projection handler.

public interface IProjectionReceivedEventReader

Remarks

The pipeline stores every received event before it folds it, and folds strictly in sequence order: an event is applied only after every earlier position of its stream was applied. The applied events of a stream therefore always form a gap-free run starting at sequence 1, and every received event above that run is waiting for a missing earlier position, or was rejected by the fold. The highest applied sequence of a stream is the sequence of its last applied record, and a gap is a position missing between 1 and the highest received sequence.

A record carries the event identity, its position and whether it was applied — never the payload or the metadata. The stored layout behind it is private to the pipeline and may change; this reader is the contract.

Reads one page of the received events of one aggregate in one tenant, in ascending sequence order.

Task<IReadOnlyList<ProjectionReceivedEvent>> ReadReceivedEventsAsync(string aggregateName, string aggregateId, string? tenantId, long afterSequence, int maximumCount, CancellationToken cancellationToken = default)

Parameters

aggregateName string

Exact aggregate contract name, spelled as the projection worker is configured with it; the stored events are kept per aggregate name, and another spelling reads a stream that received nothing.

aggregateId string

The aggregate identifier.

tenantId string

The stream's tenant; null for a tenantless stream, never empty. Events stored under another tenant, or tenantless when a tenant is named, are never returned.

afterSequence long

Returns events above this sequence only: 0 for the first page, then the last returned EventSequence.

maximumCount int

The largest number of events returned, 1 through MAXIMUM_PAGE_SIZE.

cancellationToken CancellationToken

Cancellation token.

Returns

Task<IReadOnlyList<ProjectionReceivedEvent>>

At most maximumCount received events in ascending sequence order; an empty page means no further event was received.

Exceptions

ArgumentException

Thrown before anything is read when aggregateName or aggregateId is blank or tenantId is empty.

ArgumentOutOfRangeException

Thrown before anything is read when afterSequence is negative or maximumCount is outside 1 through MAXIMUM_PAGE_SIZE.

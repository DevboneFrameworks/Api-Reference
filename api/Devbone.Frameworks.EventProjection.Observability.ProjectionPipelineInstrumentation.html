UnappliedRawEvents

Reports how many stored events wait for a missing predecessor, per aggregate.

public static readonly ObservableGauge<long> UnappliedRawEvents

Field Value

ObservableGauge<long>

Remarks

A gauge rather than a counter, because a stall is a state and not an event: a counter can say that something once went missing, never that an aggregate is still stuck. The absence of raw.events.applied increments cannot carry that either — it is indistinguishable from an idle aggregate.

A replay legitimately produces unapplied documents while it runs, so alert on this staying non-zero rather than on it being non-zero. OldestUnappliedRawEventAge is the better signal for exactly that reason.

Remarks

A separate tool cannot produce this document: the payload shapes come from a compile-time generator that runs inside the application's own build, and the routes come from its configuration. Running the application with a switch is what makes both available at once — and it works unchanged in CI, because the container image already exists.

Call it as the first statement of Main, before any host is built, so producing a catalogue never opens a database connection or a broker connection.

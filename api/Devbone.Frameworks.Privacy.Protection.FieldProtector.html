Class FieldProtector

Namespace
Devbone.Frameworks.Privacy.Protection
Assembly
Devbone.Frameworks.Privacy.dll

Protects and unprotects single string values with a subject key. Pure cryptography: it neither resolves keys nor caches them, so the write side and the projection fold keep control of resolution and of what an unreachable registry means for them.

Remarks

A refold is the read side's half of erasure by key destruction: RawEvents_* keeps ciphertext, so folding it again after the subject's key is gone yields the placeholders the tags carry, and every derived output built from the old plaintext is recomputed from the new merged document. It is not a resend, which redelivers bytes and is skipped when they are known, and not a repair, which re-runs one handler over the current merged input without touching it.

The request identity is immutable. Reuse it only with byte-equivalent request fields.

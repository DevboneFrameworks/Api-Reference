Cancellation token.

Returns

Task<ReadModelBarrierResult>

The combined state and one progress entry per barrier.

Remarks

An unreadable progress store is reported as a failed barrier rather than thrown: it is one more state a caller has to handle, not a reason to lose the commit it is asking about.

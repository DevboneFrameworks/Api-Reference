Persistence port for strongly scoped unique value tracking, including aggregate-contract and explicitly global constraints.

public interface IUniqueValueRepository

Remarks

Event rows and unique-index changes supplied to one method must commit or fail atomically. The aggregate commit pipeline supplies the last declaration per scope/key in event order; intermediate declarations are not conflict-checked. Successful scalar replacement releases the previous value. Omitted declarations retain ownership, and failed writes retain all old reservations.

Class EventStoreSchemaMismatchException

Namespace
Devbone.Frameworks.EventSourcing.Exceptions

Reports that the database an event store connects to does not have the schema this assembly requires: another schema version, or a configured table that does not exist. Raised before the store's first operation, so nothing has been written.

Remarks

The check is repeated until it succeeds once per store instance, so a store started before its database was migrated works as soon as the migration has run.

AddDevboneTelemetry(IServiceCollection, IConfiguration, Action<DevboneTelemetryOptions>?)

Registers tracing, metrics and, unless switched off, logging with OTLP export when OTLP_ENDPOINT_KEY is configured. The exporter reads endpoint, protocol, headers and timeout from the standard OTEL_EXPORTER_OTLP_* settings. Subscribes to PLATFORM_INSTRUMENTATION_PATTERN, the configured additional sources and meters, and the ASP.NET Core server instrumentation; request spans keep the route template (http.route) and lose the concrete path and the query string.

Unprotects the tagged values of a stored raw event before it is folded into raw state. This is the one place where ciphertext becomes plaintext on the read side: RawEvents_* keeps what the envelope carried, raw state and merged documents hold what the fold produced.

Remarks

A destroyed or unknown key is an expected state, not a fault: the tag's own policy supplies the placeholder or removes the property, and the fold continues. An unreachable registry throws SubjectKeyRegistryUnavailableException out of the fold, which leaves the delivery unsettled for redelivery; a value that does not authenticate throws FieldProtectionException, which the raw processor dead-letters because no retry can repair an altered ciphertext.

Without a registered ISubjectKeyRegistry the unprotector is inert until the first tagged value arrives; that value is then refused with a configuration error rather than folded as ciphertext, because a read model that holds tags instead of plaintext is a read model no query can use.

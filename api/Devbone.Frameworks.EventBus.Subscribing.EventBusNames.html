The one transport-neutral naming rule for what a subscription and its queue are built from. Both brokers read some characters as more than a name: a Kafka topic starting with ^ is a regular-expression subscription, * and # are wildcards in a RabbitMQ binding key, and a RabbitMQ queue is named {consumer}.{stream} or {consumer}.{instance}.{stream}, which is ambiguous as soon as a consumer name or an instance identity holds a dot. Each of those silently delivers another stream's messages; the rule refuses them, RabbitMQ's reserved amq. prefix, and names that would exceed the 255-byte queue-name limit.

Gets whether the operation repeats an erasure after a restore from backup. The privacy service then repeats every erasure completed since the restore point before the environment serves users again.

public bool Reapply { get; init; }

Property Value

bool

Remarks

With Reapply set the application repeats the same erasure without asking anybody: it resolves every precondition by its rules rather than reporting one as an obstacle, sends no notification (the person was told when the erasure first ran), starts no new grace period, and issues the identities NewGuid(string) derives from the case, so the repeat stays idempotent. The framework's own steps do not read it: each of them is idempotent anyway.

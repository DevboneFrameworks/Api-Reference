The one snapshot state format this platform writes and reads.

public const int SUPPORTED_SNAPSHOT_FORMAT_VERSION = 1

Field Value

int

Remarks

It is a platform-wide constant rather than a per-aggregate choice, because reading a second format would need a second serializer and none can be supplied. It is still persisted with every snapshot and carried across the gateway, so that changing the format later is a single change here: rows written by the previous version stop being readable, and the read path discards and rebuilds them from events instead of failing. Bump it only together with a serializer that produces the new shape.

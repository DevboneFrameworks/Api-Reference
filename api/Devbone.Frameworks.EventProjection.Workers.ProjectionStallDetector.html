Remarks

The pipeline applies raw events only in contiguous sequence, so a missing event leaves later ones stored and unapplied: the aggregate stalls rather than diverging. That is the better failure mode and it is the reason a global read cursor was judged unnecessary — but it only holds while someone notices the stall. Nothing else in the pipeline does: the raw processor settles the message and adds zero to the applied counter, and the pending-notification sweep only looks at events that were already applied.

Detection is separate from repair on purpose. Repair is an operator-triggered replay through the outbox, which reaches every consumer of the affected streams; this worker never triggers one, it only makes the need visible.

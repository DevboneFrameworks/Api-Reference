Remarks

The check uses the HTTP client AddDevboneSubjectKeyServiceClient registers, and is registered with the tag ready that Devbone.Frameworks.Hosting's readiness endpoint selects. Register it where a process cannot do its work without the key service, such as a writer with field protection.

Stores operator-requested outbox replays and hands each one to exactly one executing instance.

public interface IResendRequestStore

Remarks

Requests are claimed with the same conditional-update lease the outbox uses. Several application instances may poll concurrently; one wins the update, and an instance that dies mid-replay releases the request through lease expiry rather than leaving it stuck.

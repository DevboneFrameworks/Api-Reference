Remarks

Requires AddDevboneEventStore and AddDevboneEventBus. Every instance may host this: the request row's claim decides which one executes a given request, so no leader election or singleton deployment is needed.

A replay reaches every consumer of the affected streams, including applications that do not belong to the requester. On a shared broker, confirm that foreign consumers are idempotent before enabling it.

AddDevboneOutboxDispatcher(IServiceCollection, OutboxDispatcherOptions)

Registers the outbox dispatcher and, in embedded mode, the hosted service that runs it.

Parameters

The service collection.

options OutboxDispatcherOptions

Dispatcher settings including the owning event-store id and worker id.

Returns

IServiceCollection

The same service collection so calls can be chained.

Remarks

Requires AddDevboneEventStore (for IOutboxStore and IOutboxNotificationListener) and AddDevboneEventBus (for IEventBusResolver). Publication is deliberately separate from persistence: a commit is durable once the event and its outbox row are written, and delivery is a later, independently retried step.

Delivery is at-least-once. The dispatcher claims a row with a lease, publishes, then settles; a crash between publish and settle re-delivers after the lease expires, which is why consumers must settle manually and deduplicate.

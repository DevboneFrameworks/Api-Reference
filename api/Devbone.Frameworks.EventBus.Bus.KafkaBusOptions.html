MissingTopicErrorAfter

Gets or sets how long a subscribed topic may be missing at the broker before the failed consume calls are logged as errors. Until then every failed call is a warning (event 2021) with the time the topic has been missing, because a consumer that starts before its topic is provisioned is expected while a deployment comes up; after it the same event is an error with the exception. Zero makes every attempt an error, as other consume failures are. Defaults to two minutes; must not be negative.

public TimeSpan MissingTopicErrorAfter { get; init; }

PoisonMessageDeadLetterStream

Gets or sets the stream a message is moved to when this adapter cannot read it - malformed JSON, an unknown format version, a payload that does not fit the subscription's type - after MaxDeserializationAttempts attempts. The message keeps its original body and headers plus the DeadLetterHeaderNames. Only once the dead-letter stream confirmed it is the original settled; until then it is retried. Without a stream (the default) such a message is retried with a pause and blocks its partition until it is removed or the consumer can read it, which loses nothing but stops the stream.

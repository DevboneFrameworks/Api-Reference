The stored form of a protected field value: dbp:1:<keyId>:<policy>:<payload>. The JSON type stays string, so catalogue, BSON limits and JSON Merge Patch are unaffected, and any reader recognises a protected value without knowing the field definitions.

Remarks

This is a storage format. A change raises FORMAT_VERSION and the package major. A value is a tag only when all five segments parse completely; anything else is plaintext.

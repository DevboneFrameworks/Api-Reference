Remarks

Every failure to reach or read the database is SubjectKeyRegistryUnavailableException; the service maps it to 503 and a caller treats it as an infrastructure failure. A row wrapped by a key-encryption key this instance does not hold is also unavailable, not unknown: the data exists and the deployment is misconfigured or mid-rotation.

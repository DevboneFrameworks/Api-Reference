Remarks

Store this value with an accepted request. Re-resolving names during polling would allow a deployment to change what an in-flight request means. Aggregate identifiers and target sequences are deliberately absent: they become known only after the command returns its commit receipt and are combined with this frozen applicability metadata at that point.

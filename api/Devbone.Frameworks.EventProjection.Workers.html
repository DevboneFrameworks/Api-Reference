Periodically relays raw-state notifications that were applied but never published, closing the gap where a process crash between the MongoDB commit and the broker publish would otherwise leave a notification stuck until a later event happened to arrive for the same aggregate. Safe to run from multiple concurrently running worker instances: claims are per-document and lease-based (see ClaimPendingNotificationsAsync(string, int, TimeSpan, CancellationToken)).

Remarks

Built from the commit receipt the write side returns. The fields are primitives rather than the receipt type itself because this package must not depend on the DDD framework: a read model is queried by applications that never reference an aggregate, and the projection pipeline is deliberately independent of the write side.

One barrier describes one aggregate. A command that touched several aggregates produces several receipts and therefore several barriers, and "the write is visible" is the conjunction of their outcomes.

Remarks

Raw(string) and Merged(string) name the framework's own layers; anything else names an application query model, whose progress comes from the checkpoint its handler records. One name rather than a layer enum plus an optional name, because a caller storing a consistency selection stores names, and two ways of saying the same thing is how the two drift apart.

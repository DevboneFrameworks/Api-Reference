The application's decision, per field, of what an erased value looks like. It travels inside the tagged string so that a reader needs no field definitions.

Remarks

Deliberately not the ciphertext (reveals length and existence), not a hash (a stable pseudonym that correlates the erased person across documents) and not a random value (two refolds would disagree). A constant, bindable placeholder is the only form that is deterministic and keeps a stream rehydratable.

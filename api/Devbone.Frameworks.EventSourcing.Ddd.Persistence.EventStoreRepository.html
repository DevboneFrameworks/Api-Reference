Remarks

This is the Direct-mode counterpart of the Gateway-mode HttpEventPersistenceRepository. Both implement the same ports; only the transport differs.

Every write goes through ITransactionalOutboxEventStore, never through a plain event append. Persisting an event without its outbox message would produce a durable event that is never published, which no later retry can repair.

AddEventSourcingSteps(PrivacyRequestsBuilder, Action<PrivacyRequestsEventSourcingOptions>?)

Registers ISubjectEventLocator, ISnapshotEraser and IRecordExporter over the PostgreSQL event store that AddDevboneEventStore registers: the privacy index, the snapshot store, the aggregate locks and the store's settings.

Remarks

The export decrypts with the registered ISubjectKeyRegistry, which needs the key service's unprotect role. Without a registry, an export that meets a protected field fails rather than disclosing ciphertext. The steps read and write the event store directly, so an application in Gateway mode cannot use them.

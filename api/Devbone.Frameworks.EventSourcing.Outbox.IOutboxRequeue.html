Interface IOutboxRequeue

Devbone.Frameworks.EventSourcing.dll

Returns a terminally failed outbox row to dispatch. A failed row blocks every later event of its aggregate, because the claim delivers an aggregate's events in order; once the cause is fixed - a broker that was unreachable for longer than a configured attempt limit, a missing topic or exchange - an operator requeues it and the aggregate resumes. The stored envelope is published unchanged; a row whose envelope cannot be read or does not match its columns fails again on its first attempt.

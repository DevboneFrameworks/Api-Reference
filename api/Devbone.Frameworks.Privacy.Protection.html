Namespace Devbone.Frameworks.Privacy.Protection

Classes

ErasedValuePolicy

The application's decision, per field, of what an erased value looks like. It travels inside the tagged string so that a reader needs no field definitions.

FieldProtectionException

Protecting or unprotecting a value failed for a reason that is not a missing key: a plaintext that would be mistaken for a tag, an unsupported format version, a resolution for a different key, or ciphertext that does not authenticate. The message never contains the plaintext or key material.

FieldProtector

Protects and unprotects single string values with a subject key. Pure cryptography: it neither resolves keys nor caches them, so the write side and the projection fold keep control of resolution and of what an unreachable registry means for them.

JsonTagUnprotector

Unprotects every tagged string of one or more JSON documents in place, resolving the keys the tags name through a registry in batches. This is the reader's half of field protection for anyone who holds a payload without its definition: the projection fold, a rehydration mapper, an export.

ProtectedValueTag

The stored form of a protected field value: dbp:1:<keyId>:<policy>:<payload>. The JSON type stays string, so catalogue, BSON limits and JSON Merge Patch are unaffected, and any reader recognises a protected value without knowing the field definitions.

TaggedJsonValue

One tagged string found in a JSON document, together with the node that holds it, so that the unprotected value can be written back in place. Tags are self-describing, so finding them needs no definition: every reader of a payload, whether it knows the event's contract or not, walks the document the same way.

UnprotectedValue

The result of unprotecting one tagged value.

Remarks

The scenario drives AggregateRoot.HandleAsync, which is the application-facing aggregate command API. It deliberately does not drive CommandExecutor<TAggregate, TIdentity>: that type is abstract and application-owned, so a harness requiring a concrete executor would test the application's wiring rather than its domain rules.

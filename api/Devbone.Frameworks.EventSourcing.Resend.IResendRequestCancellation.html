Withdraws a resend request that is waiting or running. A replay reaches every consumer of the affected streams, including foreign applications on a shared broker, so an operator must be able to stop one without stopping every executor. A running executor notices at its next progress report - after at most one more envelope - because progress and settlement require the request to still be processing under its claim.

Coordinates optional session-scoped PostgreSQL advisory locks for globally unique aggregate identifiers.

public interface IAggregateLockStore

Remarks

This is the PostgreSQL persistence-side store: untyped string identifiers, no retry policy, one attempt per call. It is the lower of the platform's two lock abstractions.

Do not confuse it with Devbone.Frameworks.Ddd.Repositories.ILockRepository, the application-facing DDD port that is strongly typed over aggregate identity and owns the bounded retry policy. An adapter implements that port over this store; application and domain code uses the port, not this type.

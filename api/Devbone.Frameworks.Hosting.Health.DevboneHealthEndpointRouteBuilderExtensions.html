Remarks

Both answer with nothing but the aggregated status, {"status":"Healthy"}, Degraded or Unhealthy: no check names, descriptions, exceptions, durations, hosts or tenants, because the endpoints are anonymous. Why a check failed reaches the host's log through the health check service, never the response. Both endpoints carry IAllowAnonymous metadata, so a host that authenticates every request honours the probes by that standard marker.

Methods

MapDevboneHealth(IEndpointRouteBuilder, Action<DevboneHealthOptions>?)

Maps the liveness endpoint, which runs no check, and the readiness endpoint, which runs every check tagged READINESS_TAG. Healthy and degraded answer 200, unhealthy answers 503. Requires services.AddHealthChecks(); packages contribute their checks to the builder it returns.

DeleteIdentityLinkAsync(PrivacySubject, PrivacyCase, CancellationToken)

The last step of phase 2, after every refold completed: deletes the identity link (issuer, subject) and whatever else the resolver derived the key subjects from. Afterwards the resolver returns null for the account. Idempotent; not called when the resolver no longer finds the person.

EraseOwnDataAsync(PrivacySubject, PrivacyCase, CancellationToken)

Phase 1: ends the person's own aggregate with its terminal .deleted event and removes the application's own data and the files the person uploaded. It keeps the identity link and everything the resolver derives the key subjects from, so that a repeated phase 1 finds the same ones (see IPrivacySubjectResolver). Idempotent per case: derive command identities from privacyCase. Must not destroy keys; the platform does, between the two phases.

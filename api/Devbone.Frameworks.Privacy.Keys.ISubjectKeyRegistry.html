The registry of subject keys. One key per subject reference; destruction is the erasure of everything protected with it.

public interface ISubjectKeyRegistry

Remarks

Every implementation answers in input order with exactly one element per input element, accepts at most MAXIMUM_BATCH_SIZE elements per call, and distinguishes a registry that answered with an error (SubjectKeyRegistryException) from a registry that could not be reached (SubjectKeyRegistryUnavailableException). Callers rely on that distinction: a write side rejects the commit in both cases, a reader leaves its delivery unsettled only in the second.

Class CommandExecutor<TAggregate, TIdentity>

Namespace
Devbone.Frameworks.Ddd.Commands
Assembly
Devbone.Frameworks.Ddd.dll

Orchestrates one command batch against one aggregate stream without becoming an internal message bus. It acquires the aggregate lock, rehydrates state, enforces request-id idempotency, invokes generated handlers, and performs the aggregate's explicit commit only after successful handling.

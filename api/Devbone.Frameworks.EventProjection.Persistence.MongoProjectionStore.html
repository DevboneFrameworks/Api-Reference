ClaimPendingNotificationsAsync(string, int, TimeSpan, CancellationToken)

Atomically claims up to batchLimit applied-but-unpublished notifications across every aggregate instance of aggregateName. Used by the periodic outbox sweep to relay notifications that were never published because the process crashed between the MongoDB commit and the broker publish. Safe under multiple concurrently running worker instances: each document is claimed with a conditional update, so only one instance wins it per sweep, and an abandoned claim expires after leaseDuration so a later sweep (by any instance) can retry it.

public Task<IReadOnlyList<PendingRawProjectionNotification>> ClaimPendingNotificationsAsync(string aggregateName, int batchLimit, TimeSpan leaseDuration, CancellationToken cancellationToken = default)

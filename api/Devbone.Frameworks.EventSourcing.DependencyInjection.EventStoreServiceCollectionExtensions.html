Remarks

The event store is a singleton. It owns a connection factory and validated settings, and holds no per-request state. Registering it as scoped or transient multiplies Npgsql connection factories per request — a mistake that does not fail, it only degrades, which is why this registration exists.

Registering the store opens no connection. Network resources are opened only by explicit operations.

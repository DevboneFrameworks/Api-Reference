Remarks

This additive handler shape leaves IProjectionHandler unchanged. Implement it only when the handler reads related merged documents through ReadMergedAsync(string, string, CancellationToken). This includes sources already enriched into the triggering merged state: reading embedded JSON alone records no derived dependency. Increase DefinitionVersion when retrofitting tracking so existing outputs are rebuilt and acquire their missing dependency sets. Database, remote-service, and other reads outside that method remain opaque and retain conservative static CanHandle(string) triggers.

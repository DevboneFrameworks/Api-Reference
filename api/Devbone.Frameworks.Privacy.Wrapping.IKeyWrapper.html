Interface IKeyWrapper

Namespace
Devbone.Frameworks.Privacy.Wrapping

Devbone.Frameworks.Privacy.dll

Wraps subject keys with a key-encryption key the registry never stores. Implementations adapt a KMS or, for development and small deployments, a configured master key (MasterKeyWrapper).

public interface IKeyWrapper

Remarks

Rotating the key-encryption key is a rewrap of the registry, never a rewrite of data: unwrap with the old wrapper, wrap with the new, store the new material and wrapper identifier.

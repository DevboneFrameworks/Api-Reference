EnableResendRequests

Gets or sets whether operators may request an outbox replay from the diagnostics UI. Disabled by default.

public bool EnableResendRequests { get; set; }

Property Value

bool

Remarks

Even when enabled the Time Machine only records a request; it never publishes. Execution belongs to the application instances hosting the resend worker, which are the only processes with broker credentials. That separation is why a diagnostics UI embedded in an application can offer this at all.

A replay reaches every consumer of the affected streams, including other applications on a shared broker. Enabling this therefore requires ResendAuthorizationPolicy; configuration validation rejects the combination of an enabled feature and an unset policy at startup.

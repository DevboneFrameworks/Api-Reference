Stores durable, coalescing work for application-owned projection definitions.

public interface IProjectionInvalidationStore

Remarks

The invalidation is completion evidence for one aggregate-shaped execution unit. It contains no event payload or executable definition. A newer source position replaces older pending work, while claims and completions are fenced by an opaque claim token.

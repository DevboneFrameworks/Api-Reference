MigrateUniqueValueHashes6To7Async(NpgsqlConnection, string, CancellationToken)

Upgrades a schema version 6 database to version 7 by keying every stored unique-value hash. Unlike the earlier upgrades this one cannot be a SQL script: it needs the key, which is held outside the database.

public static Task<int> MigrateUniqueValueHashes6To7Async(NpgsqlConnection connection, string uniqueValueHashKey, CancellationToken cancellationToken = default)

Parameters

connection NpgsqlConnection

An open connection to the event-store database, using the default table names.

uniqueValueHashKey string

The UniqueValueHashKey every writer of this event store is configured with.

cancellationToken CancellationToken

The cancellation token.

Returns

Task<int>

The number of rewritten hashes.

Remarks

Run it exactly once, with every writer stopped, against a database that reports version 6. In one transaction it rewrites each unkeyed SHA-512 digest to h1: plus HMAC-SHA512(key, digest), adds CK_uniques_value_hash_keyed so no writer can store an unkeyed hash afterwards, and moves the version to 7; no other row changes. The digest is not kept, so the key cannot be rotated later without the plaintext values. sql/postgres/migrate-6-to-7.sql documents the same steps for review.

Exceptions

ArgumentNullException

Thrown when connection is null.

ArgumentException

Thrown when the key is missing, not base64, or shorter than 32 bytes.

InvalidOperationException

Thrown when the database does not report schema version 6.

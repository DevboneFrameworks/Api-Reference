Remarks

This is the transport-neutral half of the propagation. A transport writes CurrentHeaders() as message headers on every internal publication and maps the same two headers of a consumed message into TraceParent and TraceState; the stages continue that context with StartActivity(string, ActivityKind, string?, string?). The header names are the canonical TRACE_PARENT and TRACE_STATE the event bus uses for domain events.

A stage's activity is a child of the remote context, as the event bus consumers' are: at-least-once redelivery produces a second child of the same parent, which is what a redelivery is. The context lives in transport headers only and never in a message body, so it cannot change a message key, its ordering, the byte equality that deduplicates a stored event, or settlement. A message without the headers — one published by an older worker during a rolling deployment, or without an active trace — is processed exactly as before under a new root.

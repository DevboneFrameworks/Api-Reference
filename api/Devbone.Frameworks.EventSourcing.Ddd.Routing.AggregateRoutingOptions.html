Remarks

On a broker shared by several applications, stream names are a cross-application namespace that nothing otherwise reserves or validates. Two applications can silently choose the same stream; each then publishes into the other's topic and consumes events it cannot interpret. A convention such as ^myapp\.[a-z0-9-]+\.events$ makes that collision impossible to configure by accident.

The framework enforces the pattern, not the pattern's content: choosing and reserving the namespace is a platform-operations responsibility. Default off so an existing deployment is unaffected until it opts in.

Takes plain identifier sets rather than the bus options type on purpose: routing is persisted with the event and consumed by the write side, so it must not depend on a transport package. A caller holding EventBusTargetsOptions passes options.Targets.Keys.ToHashSet(StringComparer.OrdinalIgnoreCase) after validating those options itself.

Namespace Devbone.Frameworks.Privacy.Keys

Classes

CachingSubjectKeyRegistry

Caches registry answers per caller, bounded in time by the registry's window and the caller's own maximum, and bounded in size. A destruction through this instance evicts immediately; a destruction elsewhere becomes visible when the cached answer expires, which is the window the guide states.

InMemorySubjectKeyRegistry

A registry held in process memory, for tests of the write side, the worker and application code. It keeps the semantics of the key service: get-or-create is idempotent and race-safe, a destroyed subject that returns receives a new key, destruction is idempotent, and an unavailable registry throws SubjectKeyRegistryUnavailableException rather than answering.

SubjectKeyBatch

Validates registry request batches the same way in every implementation, so that a registry of the application's own (over a KMS, for example) rejects what the platform's registries reject.

SubjectKeyCacheOptions

Bounds the per-caller key cache of CachingSubjectKeyRegistry.

SubjectKeyDestruction

The audit record of a key destruction. It carries no key material and no subject reference; the identifier is opaque.

SubjectKeyErrorCodes

The stable error codes of the key registry and the key service wire contract.

SubjectKeyMaterial

An active subject key with its material, as returned to a caller that protects values.

SubjectKeyReference

Identifies the data subject a key belongs to: the pseudonymized triple the event privacy index already records per event. The same triple names the same key, so the reference must be stable and must never be a raw personal value.

SubjectKeyRegistryException

The registry answered and rejected the request. The message never contains key material or a subject reference.

SubjectKeyRegistryUnavailableException

The registry could not be reached or could not answer. A write side rejects its commit; a reader leaves its delivery unsettled and retries. Never a dead letter, never a placeholder.

SubjectKeyResolution

The registry's answer for one key identifier a reader asked about.

Structs

SubjectKeyId

The registry-assigned identifier of one subject key: 32 lowercase hexadecimal characters. It is never derived from the subject reference, so a tag carrying it reveals nothing about the subject.

Remarks

Everything registered here is a singleton. The adapter is stateless; the event store owns a connection factory and no per-request state.

This does not register a bus or an outbox dispatcher. Persistence and publication are separate concerns: a commit is durable once the event and its outbox row are written, and delivery is a later, independently retried step.

It does register the canonical envelope serializer, because an outbox row carries an envelope and the mapper cannot be constructed without one. The registration uses TryAdd, so an application that registers its own serializer keeps it, and calling AddDevboneEventBus as well does not produce a second instance - the bytes written to an outbox row and the bytes published must be identical.

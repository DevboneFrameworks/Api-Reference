Remarks

The check reads KafkaProjectionReadiness, which AddDevboneKafkaEventProjection registers, and is registered with the tag ready that Devbone.Frameworks.Hosting's readiness endpoint selects. Register it only in a process whose configured transport is Kafka: a process running RabbitMQ starts no Kafka consumer and would never be ready.

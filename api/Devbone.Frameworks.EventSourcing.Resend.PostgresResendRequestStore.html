ReadPublishedAsync(ResendRequest, int, CancellationToken)

Reads the next batch of published envelopes matching a replay request.

Parameters

request ResendRequest

Replay scope and filters.

batchSize int

Maximum envelopes to return.

cancellationToken CancellationToken

Cancellation token.

Returns

Task<IReadOnlyList<OutboxMessage>>

The next envelopes, grouped by aggregate and in stream order. Empty when finished.

Remarks

Ordered by aggregate identifier then event sequence, and resumed from the request's cursor, so a replay that is interrupted continues where it stopped instead of restarting.

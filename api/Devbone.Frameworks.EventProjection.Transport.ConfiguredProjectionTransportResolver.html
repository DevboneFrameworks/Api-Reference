Remarks

This package is transport-neutral: it knows how to resolve a configured name to a provider, not how to talk to a broker. Supply the provider from the transport package you actually use — Devbone.Frameworks.EventProjection.Kafka or Devbone.Frameworks.EventProjection.RabbitMq — so that an application running on one broker does not ship the other's client.

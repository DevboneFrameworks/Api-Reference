BroadcastInstanceId

Gets or sets the identity of this application instance for broadcast-per-instance subscriptions. Required for every BroadcastPerInstance subscription: use a value that is stable for one replica across restarts and distinct between replicas and processes, for example a StatefulSet ordinal. There is no machine-name fallback, because two processes on one host would share it and each receive only part of the broadcast.

BroadcastQueueExpiry

Gets or sets how long a broadcast-per-instance queue survives without a consumer before RabbitMQ deletes it (x-expires). A short restart keeps the queue and its messages; the queue of an instance that is gone for good disappears instead of collecting every message until the broker blocks its publishers. Defaults to one hour; must be positive and at most 24.8 days, the largest value RabbitMQ accepts.

PoisonMessageDeadLetterStream

Gets or sets the stream a message is moved to when this adapter cannot read it - malformed JSON, an unknown format version, a payload that does not fit the subscription's type - after MaxDeserializationAttempts attempts. The message keeps its original body and headers plus the DeadLetterHeaderNames. Only once the dead-letter stream confirmed it is the original settled; until then it is retried. Without a stream (the default) such a message is returned after RedeliveryDelay and blocks its queue until it is removed or the consumer can read it, which loses nothing but stops the stream.

public string? PoisonMessageDeadLetterStream { get; init; }

RedeliveryDelay

Gets or sets how long the subscriber waits before it returns a message to the queue - when the handler threw, did not commit, or the message cannot be read. RabbitMQ redelivers a requeued message at once, so without a pause a failing message loops as fast as the broker can deliver it. Deliveries on one channel are handled one at a time, so the pause holds back the following messages and queue order is kept. Defaults to one second; zero disables it; at most one hour.

public TimeSpan RedeliveryDelay { get; init; }

Answers, once and without blocking, whether the read models have observed a set of committed positions.

public interface IReadModelConsistencyBarrier

Remarks

This is the primitive. IReadModelWaiter is a bounded wait built on top of it, for the case where a caller wants to hold its request briefly; everything that returns early and lets the client come back — a queued response, a status endpoint, a polling orchestrator — uses this instead and owns its own retry rhythm.

One call, one batch. Barriers are grouped by layer and aggregate type into one keyed query each, so checking fifty positions does not become fifty round trips.

Read-only and safe to call at any frequency. It never claims, mutates or advances anything.

Remarks

An unreadable progress store is reported as a failed barrier rather than thrown: it is one more state a caller has to handle, not a reason to lose the commit it is asking about.

Creates the publisher, consumer, and topology initializer of one concrete projection transport.

public interface IProjectionTransportProvider

Remarks

This is the seam that keeps Devbone.Frameworks.EventProjection free of broker clients. The pipeline resolves exactly one provider — the one whose TransportName matches the configured Transport — and never sees a broker type itself.

Implementations create configured adapters only. Opening connections, declaring topology, and consuming belong to the returned adapters' explicit publish, initialize, and run operations, never to construction.

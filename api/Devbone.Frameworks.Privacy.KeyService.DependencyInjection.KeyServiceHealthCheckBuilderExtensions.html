Remarks

The check needs AddDevboneKeyService and a registry registration, and is registered with the tag ready that Devbone.Frameworks.Hosting's readiness endpoint selects. A process that only calls a key service uses AddDevboneKeyServiceClientHealthCheck from Devbone.Frameworks.Privacy instead.

Reports how a wait ended. Every value except CaughtUp means the caller must decide what to do, which is why they are distinguished rather than collapsed into one failure.

public enum ReadModelWaitOutcome

Fields

CaughtUp = 0

The observed layer reached the requested event sequence or a later one. The query that follows sees the commit.

Rejected = 3

The wait was refused because too many waits were already in flight. Load shedding: the request has not been observed at all, and the caller should degrade rather than queue behind the cap.

Stalled = 2

The event reached the read side and cannot be applied, because an earlier event of the same stream is missing. The pipeline stalls rather than diverging, so this never resolves by waiting longer and the wait is abandoned immediately instead of burning the remaining budget. Closing the gap is an operator action.

Timeout = 1

The budget expired while the projection was still behind. Ordinary under load and the outcome to map onto a deferred or queued response, because the projection is still progressing.

Namespace Devbone.Frameworks.EventSourcing.Ddd.Privacy

Classes

EventPrivacyCatalogCheck

Verifies at startup, against the generated contract catalogue, that every protected privacy field is a string and that a field removed on erasure is nullable and optional. The store enforces the same at commit; this check fails composition instead of the first command.

EventPrivacyCatalogGaps

The three ways the registered privacy definitions and the generated contract catalogue can disagree, as found by FindGaps(IReadOnlyCollection<EventPrivacyDefinition>, IReadOnlyCollection<string>?, IReadOnlyList<EventContractDescriptor>?). Empty on every list means every contract and every field is either classified or declared non-personal, and every definition names something that exists.

StoredEventFieldProtection

Applies field protection to DDD stored events before the envelope and the database row exist, and removes it from stored rows on the way back to the DDD contract. Both the Direct-mode repository and the Gateway service run their events through this class, so the two modes protect identically.

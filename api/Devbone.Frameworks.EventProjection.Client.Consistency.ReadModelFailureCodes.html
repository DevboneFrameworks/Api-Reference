Stable because a caller branches on them: a message is for a human, a code is for a switch. Only codes this package can actually produce are declared.

Remarks

Failing rather than pending is the whole point. A typo or a removed definition would otherwise present as a projection that is merely slow, and a caller would poll for it until its deadline expired. A known definition whose workers never started or whose leases expired uses PROJECTION_UNAVAILABLE.

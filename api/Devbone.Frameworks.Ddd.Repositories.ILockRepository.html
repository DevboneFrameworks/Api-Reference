Coordinates exclusive aggregate ownership and returns a disposable lease to the successful caller.

public interface ILockRepository

Remarks

This is the application-facing DDD port. It is strongly typed over the aggregate identity, applies a bounded retry policy, and is what CommandExecutor depends on. An application implements or registers it; it does not talk to a database itself.

Do not confuse it with Devbone.Frameworks.EventSourcing.Locks.IAggregateLockStore, which is the PostgreSQL advisory-lock store on the persistence side: untyped, no retry policy, and one layer below this port. An adapter implements this interface over that store.

Remarks

Throw it from InitializeAsync(CancellationToken) only when no broker answered — a connection, name-resolution or all-brokers-down failure, or a timeout before any answer. Host startup then retries the initializer with backoff and logs a warning until UnreachableDependencyErrorAfter has passed, and only then lets this exception fail the host. Every other exception — absent topics, refused authentication or authorization, invalid configuration — fails startup at once, because waiting cannot correct it.

It derives from InvalidOperationException, so the failure a host reports once the wait is over is the same exception type and message as an initializer that does not distinguish the two cases.
